# GitHub 发布副本说明

原课程实验及封存目录保持不变。此仓库是独立整理的发布副本。

为便于迁移所作的修改：

- 资源、数据和输出路径改为仓库相对路径，并允许环境变量覆盖。
- MJCF 仅将 meshdir 改为相对路径，保留机械臂参数、场景、控制频率和成功判据。
- 从历史收集管线中拆出原 `ResetPlacement` 类及两个专家辅助函数，避免导入与本任务无关的训练管线。函数主体不改。
- 本地 VLM 小配置和最终 tokenizer 随仓库保存，加载器严格读取外部权重。
- 阶段采样直接复用封存锚点列表，因为部分原始逐帧阶段审计已经清理。锚点序列及各阶段 80×256 条目不变，换数据时需重新准备采样计划。
- 运行目录的剩余空间检查改为当前输出文件系统，不再要求存在 D 盘。
- 对结果和协议中的绝对个人路径作占位替换，保留逐次科学指标。原文件哈希记录于 `records/source-provenance.json`。
- 保留原实验的研究支持模块，新的正式运行入口仅暴露文档列出的训练、续训、推理和离线验证命令。历史自动调度及课程报告导出不作为此发布副本的一键复现入口。

未上传：完整图像 Parquet、最终与 Base 大权重、历史检查点、运行缓存、凭据、个人课程文档、失败视频全集。

本地核验结果写入 `records/release-checks.json`。核验不代表重新复现了全部训练或 200 次正式评估；原历史成绩来自随仓库提供的实验记录。
