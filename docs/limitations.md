# 现有问题与改进方向

以下属于分析和后续实验计划，不是已经取得的新成绩。

## 位姿与数据覆盖

输入包含 RGB 和机器人关节配置，未显式输入物块数值位姿。关节配置可用于计算机械臂末端位姿，但不能独立确定物块位置。图像中已有物块位置与朝向的视觉线索，因此不能说训练完全不含几何信息。

后续可以比较原输入、增加仿真真值相对位姿、增加视觉估计相对位姿。真值组只作诊断上限，视觉组才包含实际感知误差。优先补充边界、抓偏、滑脱和托盘外恢复示教，并在固定训练预算下比较收益。

## 语言与视觉泛化

原训练和正式测试使用固定英文指令，同义改写与中文描述尚未验证。应先开放真实入模文本，在配对位置上比较语义一致的改写，并检查不同任务意图是否改变行为。

现有光照仅比较 100% 与 90%，不足以证明强阴影、遮挡、背景或相机变化下的鲁棒性。后续每次只增加一种扰动。

## 任务效率

成功示教平均约 27.32 秒，微调模型成功任务平均约 28 秒，说明动作节奏较保守。正常光 50 次运行中的实际关节速度峰值约 0.752 rad/s。目标每 20 ms 最大变化 0.03 rad，相当于目标变化率上限 1.5 rad/s，这不等于实测关节速度。

可以优先加快空载接近和撤离，抓取、放置时保留细致反馈。分别研究运动速度、执行窗口和推理等待，避免仅提高控制更新频率就宣称提速。先约 20 秒、再 15～18 秒是待验证目标，当前没有提速实验结果。

同步推理暂停物理仿真，因此模型推理时间增加的是现实等待时间。异步执行可能改善现实效率，还需处理观测延迟、新旧动作块衔接和过期动作。

## 完成阶段与恢复

结合目标指令、实际夹爪开度、双侧接触和托盘支撑时间，检查持物、释放、撤离的顺序。可分别对照完成阶段重采样、恢复示教和接触辅助，单独报告辅助模块带来的收益。

## 评价设计

统一完整成功标准，至少同时报告成功率、成功平均仿真时间、全部试次现实耗时、推理延迟和失败类别。开发位置可以反复调试，最终确认必须使用另行冻结的新位置。现有有限样本结果不能直接推断真实硬件部署能力。
