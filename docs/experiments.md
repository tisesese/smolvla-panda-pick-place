# 实验过程与结果口径

## 数据来源

100 条成功专家轨迹，共 136,589 帧，记录频率 50 Hz，平均记录时长约 27.32 秒。原 40 条和新增 60 条共同构成数据集；10×6 分层网格对应新增 60 条，不应描述为全部 100 条都来自该网格。

固定 Train80 共 109,268 帧，Validation20 共 27,321 帧。划分见 `data_metadata/panda_100_lowdisk/split.json`，训练统计仅来自 Train80。每条训练轨迹取 256 个锚点，80 条合计 20,480 个条目。批次打乱并重复抽取锚点，20,000 次更新不是只训练 20,000 个独立样本。

## 四阶段谱系

1. **20k 初始模型**：建立行为克隆基线，5 个开发位置 0/5。训练损失下降未转化为完整抓放成功。
2. **20k 至 22k**：比较尾层适配、任务区域裁剪和视觉连接及最后视觉层训练。默认执行仍因接触保护或超时未通过筛查。
3. **22k 至 27k**：动作标签间隔从 20 ms 改为 100 ms，预测时域从约 1 秒扩至约 5 秒，底层仍以 50 Hz 插值执行。27k 小样本开发验证达到 4/5，但扩展开发位置仅 32/50，继续改进。
4. **27k 至 33k**：将最终采样改为全程 64 个，加接近、下降抓取、抬升、支撑、释放、撤离各 32 个。降低学习率，扩大开发验证后选择 33k。

累计更新为 20,000＋2,000＋5,000＋6,000。旁支诊断不计入最终权重谱系。候选表现并不随步数单调提升。33k 开发筛查为 19/20，50 个开发位置上两组动作噪声为 50/50 与 47/50。二者复用同一组开发位置，不能称为 100 个不同位置。

## 正式配对实验

冻结模型和执行协议后，另取 50 个唯一位置，每组 40 内部＋10 边界，四组共 200 次。位置索引、种子、动作噪声和逐次指标见 `results/results.jsonl`，执行协议见 `results/protocol.json`。

```bash
python scripts/summarize_results.py --check
```

该命令核对每组样本数、索引唯一性和四组位置配对，重新计算成功次数与成功任务平均仿真时间。动作噪声设置见冻结协议。Base 无成功任务时平均成功耗时为空，不用 0 秒代替。计算时先消除远小于 2 ms 物理步长的浮点累计误差，显示采用小数点后两位。

## 学习损失

`records/training/*/updates.jsonl` 保留优化器更新损失。各阶段训练目标、动作时域和采样分布不同，不能根据跨阶段 loss 高低直接排序模型。

`records/selection/final-validation-loss.json` 是最终模型补做的离线验证，20 条轨迹、每条 6 个固定时刻、共 120 个样本，平均约 0.003315。该核验不执行优化器更新，也未用于正式测试后的模型选择。它是一个最终模型验证点，不能画成不存在的完整验证损失曲线。

## 失败分析

Base 的 100 次均在有效抓取和抬升前失败。33k 的 100 次中共 9 次失败，8 次结束时已入盘但释放验收未通过，1 次未完成入盘。该分类描述最终现象，不能直接当作唯一根因。

`records/diagnostics/` 保存覆盖、接触、映射与时序诊断。视觉误判需要独立几何证据，不能仅看视频即认定。当前边界位置表现较弱，持物与释放衔接仍是改进重点。
